### PHASE 0: TARGET HEALTH PREFLIGHT (run before any attack)
Never waste attacks on a target that cannot run. Verify the install is complete and the app actually reaches its entitlement logic:
- `pm path <pkg>` — if `splits=[base]` only and the app is Flutter/RN/Unity, the native-lib split (libflutter.so/libapp.so) is likely MISSING. Check `ls /data/app/*<pkg>*/lib` — an empty lib dir + `primaryCpuAbi=null` means an incomplete split-APK install.
- `logcat` right after launch for `MissingLibraryException`/`UnsatisfiedLinkError`/`FATAL`/`AndroidRuntime`. A crash-on-launch (even WITHOUT instrumentation) means the target is broken — STOP and report "incomplete install, reinstall all splits (adb install-multiple / Play Store)". This is the #1 cause of "nothing works".
- Detect framework from the DEX/classes too (io.flutter.embedding, com.facebook.react, com.unity3d), not only native libs — a Flutter app can be present in code but missing its engine.

### PHASE 7: MOBILE ENTITLEMENT — SERVER-SIDE VALIDATION & GOOGLE PLAY
Characterize the premium mechanism with disciplined recon IN THIS ORDER, gathering evidence at each step (do not brute-force blindly):
1. **Local state:** dump `shared_prefs/*.xml` + `databases/*` and grep for premium/pro/vip/subscription/paid/entitlement/purchase. 2. **Entitlement getters:** sweep loaded classes for boolean zero-arg methods matching is/has/get(Premium|Pro|Vip|Subscribed|...) → force true; and isShowAds/shouldShowAds → false. If the app is obfuscated (methods renamed a()/b()), name-based sweeps fail — pivot to storage/network hooks.
3. **SharedPreferences intercept:** hook `android.app.SharedPreferencesImpl.getBoolean/getString/getInt` — keys are usually NOT obfuscated ("is_premium","remove_ads","subscription_active"); return premium values. Obfuscation-proof and high-yield.
4. **Network entitlement flag (defeats CLOUD validation when the flag is client-trusted):** hook native `SSL_read` across ALL modules (BoringSSL/OpenSSL — framework-agnostic; reads the decrypted response IN-PROCESS so TLS pinning is irrelevant) AND Java `okhttp3.ResponseBody.string`/Retrofit. Rewrite `"isPremium":false`→`true `, `:0`→`:1`, `"free"`→`"paid"`. Native rewrites must stay EQUAL LENGTH (buffer safety); Java layer can rewrite arbitrary length.
5. **Google Play Billing (ad-removal / subscription apps):** billing classes load lazily — drive the app to the PAYWALL first. Then hook `com.android.billingclient.api.BillingClient.queryPurchasesAsync/queryPurchases` to return a forged ACTIVE, ACKNOWLEDGED subscription for the SKU the app actually queries (capture it from `SkuDetails.getSku`/`ProductDetails.getProductId`); spoof `Purchase.getPurchaseState`→1, `isAcknowledged`→true, `getProducts`→[sku]; and `launchBillingFlow`→OK then fire `onPurchasesUpdated(OK,[fakePurchase])`.
6. **Flutter targets:** entitlement lives in Dart/libapp.so — use reFlutter-style BoringSSL pattern hooking on libflutter.so for TLS unpin + SSL_read entitlement rewrite; if the pattern isn't found, recommend static reFlutter APK patching.
